## 메인 페이지 구성

### 섹션 1: 히어로 뉴스 슬라이더
- 3장 자동 슬라이드 (자동재생 + 정지 버튼)
- 대형 이미지 + 제목 + 설명 + "자세히 보기" CTA
- 좌우 화살표 네비게이션
- 해시태그 링크 (#Kanana)

### 섹션 2: 서비스 바로가기 (4개 카드)
- 서비스 — "나의 세계를 바꾸는 카카오"
- AI 기술 — "나에게 가장 가까운, 가장 쉬운 AI"
- 채용 — "함께 나아갈 미래의 크루들에게"
- ESG — "지속가능한 미래를 위한 카카오의 약속과 책임"
- 각 카드: 제목 + 부가 설명 + 링크

### 섹션 3: 카카오의 다양한 모습 (5개 링크 카드)
- 뉴스, 투자정보, 카카오소식, 그룹사소식, 고객센터
- 각 카드: 제목 + 설명 + 링크

### 섹션 4: 서비스 캐러셀
- "더 나은 세상을 만드는 카카오 서비스"
- 카카오톡, 카카오맵, 카카오톡 채널, 카카오페이지 등
- 가로 스크롤 슬라이더 (8개 중 4개 노출)
- 각 카드: 서비스명 + 한 줄 설명

### 섹션 5: 메가 푸터
- 오늘의 카카오 (주요 서비스 링크)
- 카카오 그룹의 서비스 (카테고리별: 커뮤니케이션, 일상편의, 비즈니스, 쇼핑, 엔터테인먼트, 임팩트)
- 카카오그룹 (계열사 링크 12개+)
- IR (기업지배구조, 주가정보, 재무정보 등)
- 계정 및 지원 (카카오계정, 프라이버시, 고객센터, 인재영입)
- 서비스 이용정보 (이용약관, 개인정보처리방침, 운영정책, 청소년보호정책 등)

## 디자인 특징

### 컬러 (밝은 버전)
- Background: #FFFFFF (순백)
- Text Primary: #191919 (거의 블랙)
- Text Secondary: #666666
- Accent: 카카오 옐로우 (#FEE500) — 포인트로만 사용
- Section BG: 화이트 + 연한 그레이(#F9F9F9) 교차
- CTA: 다크 버튼 or 텍스트 링크

### 타이포그래피
- 한글: 산세리프 (깔끔, 가독성)
- 영문: 산세리프 (일관)
- 헤딩: 볼드 + 큰 사이즈 (28~40px)
- 본문: 라이트/레귤러 (14~16px)
- 자간: 넓은 편 (여유로움)

### 레이아웃
- 넓은 여백 (최소 80px+ 섹션 간격)
- 최대 너비 제한 (1200px 내외)
- 카드형 UI (둥근 모서리, 그림자 없거나 미미)
- 그리드: 2열 또는 4열
- 깔끔한 수평선 구분

### 반응형
- 데스크탑: 다열 그리드
- 태블릿: 2열
- 모바일: 1열 스택 + 햄버거 메뉴

### UX 특징
- 다크모드 토글 버튼 (헤더에 위치)
- 다국어 전환 (한/영)
- 검색 기능
- 메가 메뉴 (hover 시 드롭다운)
- 자동 슬라이드 + 정지 버튼 (접근성)
- 메가 푸터 (방대한 링크 정리)
