## 메인 랜딩페이지 구성

### 섹션 1: 상단 배너
- 프로모션 배너 바 (링크형)
- "리멤버에서 450만 경력직 인재를 찾아보세요" + CTA 버튼
- 앱 다운로드 버튼

### 섹션 2: 커리어 (Career)
- SVG 타이틀 이미지
- 핵심 메시지: "프로필 등록하면 스카웃 제안이 찾아와요!"
- 부가 설명: "내 경력과 전문성에 딱 맞는 제안을 만나보세요."
- CTA 링크: "지금 프로필 등록하기"
- 배경 일러스트 (SVG)

### 섹션 3: 비즈니스 (Business)
- SVG 타이틀 이미지
- 핵심 메시지: "촬영 한 번으로 명함관리 쉽게 해요!"
- 부가 설명: "내 인맥의 이직, 승진 소식도 받아보세요."
- CTA 링크: "명함 관리 시작하기"
- 배경 일러스트

### 섹션 4: 커뮤니티 (Community)
- SVG 타이틀 이미지
- 핵심 메시지: "업계 사람들과 깊이 있게 소통해요!"
- 부가 설명: "커리어 고민과 직장 생활의 노하우를 공유해요."
- CTA 링크: "커뮤니티 바로가기"
- 카드 캐러셀 (커뮤니티 게시물 미리보기)

### 섹션 5: 나우 (Now) — 전문가 브리핑
- SVG 타이틀 이미지
- 핵심 메시지: "전문가 브리핑으로 인사이트 충전해요!"
- 부가 설명: "매일 아침, 국내 최고 전문가들의 경제 브리핑을 받아보세요."
- CTA 링크: "바로 읽어보기"
- 카드 캐러셀 (브리핑 미리보기)

### 섹션 6: 기업용 서비스
- 제목: "우리 회사 비즈니스도 맞춤 솔루션이 필요해요!"
- 4개 서비스 카드 (링크형):
  1. 채용 솔루션 — "다른 곳에는 없는 핵심 인재들을 만나보세요"
  2. 광고 상품 — "잠재 고객을 타깃하고 제품을 효과적으로 알리세요"
  3. 리서치 서비스 — "설문조사와 전문가 인터뷰를 통해 고객의 정확한 니즈를 파악하세요"
  4. 기업용 명함 관리 — "소중한 회사의 영업자산 팀 명함첩으로 관리하세요"

### 섹션 7: 푸터
- 법적 링크: 회사소개, 이용약관, 위치기반 서비스 이용약관, 개인정보처리방침, 도움말
- 문의하기 버튼
- 기업용 서비스 드롭다운
- 대표전화, 주소, 대표자, 사업자등록번호, 통신판매업 신고번호

## 회사 소개 페이지 (corp.remember.co.kr)

### 구성
- 히어로: "프로를 위한 모든 기회, 리멤버가 연결합니다" (대형 타이포)
- 서비스 카테고리별 소개:
  1. HR Network Service (채용솔루션, 헤드헌팅, 개인용 서비스)
  2. Expert Network Service (전문가 1:1 인터뷰, 설문조사)
  3. Business Network Service (명함관리, 커뮤니티, 선물하기, 광고상품)
- 각 서비스마다 설명 + CTA 링크
- 푸터: 회사 정보 + SNS 링크 (Blog, LinkedIn, Facebook, Brunch)

## 디자인 특징

### 컬러
- Primary: 블루 계열 (신뢰감)
- Background: 화이트 + 연한 그레이 섹션 교차
- Text: 다크 (#222)
- CTA: 블루 또는 블랙 버튼

### 타이포그래피
- 서비스명: SVG 이미지로 처리 (커스텀 로고 타이포)
- 핵심 메시지: 큰 볼드 한글 (24~32px급)
- 부가 설명: 작은 그레이 텍스트 (14~16px)
- 영문 섹션 타이틀: 세리프 또는 산세리프 대문자

### 레이아웃
- 원페이지 세로 스크롤
- 섹션마다 배경 일러스트 (SVG)로 시각적 변화
- 좌측 텍스트 + 우측 비주얼 패턴 반복
- 카드형 캐러셀 (커뮤니티, 브리핑)
- 기업용 서비스는 2×2 카드 그리드

### 반응형
- 데스크탑: 좌우 분할 레이아웃
- 모바일: 세로 스택, 텍스트 → 이미지 순서

### UX 특징
- 상단 프로모션 배너 (클릭 유도)
- 각 섹션마다 명확한 CTA 링크 (1개씩)
- 섹션별 독립적 — 순서 변경/추가/삭제 용이
- 앱 다운로드 유도 (모바일 앱 서비스이므로)

## 템플릿 변환 시 핵심 섹션 (재사용 가능)
1. 상단 프로모션 배너 바
2. 히어로 섹션 (대형 타이포 + 배경)
3. 서비스 소개 섹션 (SVG 타이틀 + 메시지 + CTA + 배경 일러스트) x 반복
4. 카드 캐러셀 (미리보기 카드 슬라이드)
5. 서비스 카드 그리드 (2x2, 제목 + 설명 + 링크)
6. 푸터 (법적 정보 + 문의 + SNS)

## 랜딩페이지 템플릿으로서의 장점
- **섹션 기반 구조**: 블록을 추가/제거/순서변경 가능
- **반복 패턴**: "타이틀 + 메시지 + CTA + 비주얼" 공식이 일관됨
- **CTA 집중**: 각 섹션마다 1개의 명확한 행동 유도
- **심플한 네비게이션**: 원페이지이므로 복잡한 메뉴 불필요
