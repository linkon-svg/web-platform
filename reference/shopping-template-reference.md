# 쇼핑몰 템플릿 레퍼런스 — 솔리드옴므 (solidhomme.com)

## 사이트 개요
- 프리미엄 남성 패션 브랜드 공식 온라인 스토어
- 의류, 액세서리, 슈즈 판매
- 카페24 기반 커스텀 디자인

## 사이트 구조 (Sitemap)

### 메인 네비게이션
1. **쇼핑** (/product/list.html?cate_no=42) — 전체 상품 목록
2. **컬렉션** — 시즌별 컬렉션 (드롭다운)
3. **매장** (/stores.html) — 오프라인 매장 안내
4. **소식** (/product/news.html?cate_no=77) — 뉴스/캠페인

### 헤더 유틸
- 로고 (좌측)
- 통화 선택 (KRW)
- 검색
- 회원 로그인
- 장바구니

## 페이지별 구성

### 1. 메인 페이지 (/)

#### 상단 배너
- 프로모션 바: "전 상품 무료 배송 & 무료 반품"
- 좌우 화살표 슬라이드

#### 새로운 상품 섹션
- "새로운 상품" + "더 많은 상품 보기" 링크
- 상품 카드 5개 가로 나열
- 각 카드: 상품 이미지 + 위시리스트 하트 + 상품명 + 가격 + 빠른 구매

#### 선물 제안 섹션
- "선물 제안" 소제목
- "2026 봄-여름" 대형 헤딩
- 시즌 설명 카피
- 풀스크린 이미지 배경

#### 추천 상품 섹션
- "추천 상품" 소제목
- "타임리스 에센셜 액세서리 컬렉션" 헤딩
- 상품 카드 6개 (2열 × 3행 또는 가로 스크롤)
- 각 카드: 이미지 + 위시리스트 + 상품명 + 가격

#### 카테고리 배너 섹션
- 4개 카테고리 배너 (이미지 + 타이틀 + 설명):
  1. 새로운 상품 — "2026 봄-여름 시즌을 위한 상품"
  2. 아웃웨어 — "새롭게 재해석 되는 하나의 작품"
  3. 악세서리 — "기능성을 겸비한 섬세한 컬렉션"
  4. 슈퍼 노멀 — "일상의 기억을 담은 아카이브"

#### 새로운 소식 섹션
- 캐러셀 슬라이드 (뉴스/캠페인 카드)
- 각 카드: 이미지 + 카테고리 태그(소식/캠페인) + 제목
- 8개 카드 순환

### 2. 상품 목록 (/product/list.html)
- "쇼핑" 페이지 타이틀
- 필터 기능
- 상품 그리드 (4열)
- 각 카드: 이미지 + 위시리스트 + 상품명 + 가격 + 빠른 구매
- 페이지네이션 (1,2,3,4,5 + 이전/다음)

### 3. 상품 상세 (/product/detail.html)
- 좌측: 상품 이미지 (여러 장, 세로 스크롤)
- 우측: 상품 정보
  - 상품명
  - 가격 (KRW)
  - 컬러/사이즈 선택
  - 수량
  - 장바구니 / 바로구매 버튼
  - 위시리스트 버튼
- 하단: 상품 설명, 소재 정보, 배송/반품 안내

### 4. 매장 안내 (/stores.html)
- 매장 목록 (국내/해외)
- 매장명 + 주소 + 전화번호

### 5. 소개 (/about.html)
- 브랜드 히스토리
- 브랜드 철학
- 이미지 중심 레이아웃

### 6. 뉴스 (/product/news.html)
- 뉴스/캠페인 카드 그리드
- 카테고리 태그 (소식, 캠페인)
- 이미지 + 제목

## 디자인 특징

### 컬러
- Background: #FFFFFF (순백)
- Text Primary: #000000 (블랙)
- Text Secondary: #999999 (그레이)
- Accent: 없음 (모노크롬 — 흑백 위주)
- 상품 카드: 배경 없음, 깔끔한 이미지 중심
- CTA 버튼: 블랙 배경 + 화이트 텍스트

### 타이포그래피
- 영문: 세리프 (브랜드명, 헤딩) — 럭셔리/클래식 느낌
- 한글: 산세리프 (얇은 웨이트)
- 가격: 산세리프, 레귤러
- 전체적으로 얇고 우아한 폰트 사용
- 자간: 넓은 편 (영문 특히)

### 레이아웃
- 미니멀리즘 극대화
- 넓은 여백 (100px+)
- 상품 이미지가 주인공 (텍스트 최소화)
- 그리드: 4열 (상품 목록), 5열 (메인 신상품)
- 풀스크린 이미지 배너 (시즌 캠페인)
- 깔끔한 수직 스크롤

### 반응형
- 데스크탑: 다열 그리드, 넓은 여백
- 모바일: 2열 그리드, 햄버거 메뉴

### UX 특징
- 위시리스트 하트 (상품 카드 위 오버레이)
- 빠른 구매 버튼 (상품 카드 호버 시)
- 프로모션 배너 바 (무료배송 안내)
- 뉴스레터 구독 폼 (푸터)
- 통화 선택 (KRW)
- 상담 챗봇 버튼

## 푸터 구성
- 4개 카테고리:
  1. 소개: 솔리드 소개, 연락
  2. 고객서비스: 이용안내, 고객 문의, 주문배송 조회, 온라인 멤버십, 오프라인 마일리지
  3. 법적고지: 개인정보 보호정책, 이용약관
  4. 소셜 미디어: 인스타그램, 유투브
- 뉴스레터 구독 (이메일 입력 + 동의 체크 + 구독 버튼)
- 사업자 정보 (회사명, 사업자번호, 통신판매업, 대표자, 주소, 전화, 이메일)
- SNS 아이콘 (인스타그램, 페이스북, 유튜브)

## 템플릿 변환 시 핵심 섹션 (재사용 가능)
1. 헤더 (로고 + 메뉴 + 통화 + 검색 + 로그인 + 장바구니)
2. 프로모션 배너 바 (무료배송 등 안내)
3. 상품 카드 (이미지 + 위시리스트 + 상품명 + 가격 + 빠른구매)
4. 상품 그리드 (필터 + 4열 그리드 + 페이지네이션)
5. 상품 상세 (좌: 이미지 갤러리 / 우: 정보+구매)
6. 시즌 배너 (풀스크린 이미지 + 오버레이 텍스트)
7. 카테고리 배너 그리드 (이미지 + 타이틀 + 설명) x 4
8. 뉴스/캠페인 캐러셀
9. 매장 목록 (이름 + 주소 + 연락처)
10. 뉴스레터 구독 폼
11. 쇼핑몰 푸터 (카테고리별 링크 + 사업자정보 + SNS)
