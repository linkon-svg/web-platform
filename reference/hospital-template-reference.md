## 페이지별 구성

### 1. 메인 페이지 (/)
- **히어로 섹션**: 풀스크린 이미지 (클리닉 분위기)
- **철학 섹션**: 4가지 가치 (Healthy, Naturally, Safely, Beauty) — 아이콘 + 설명
- **시술 소개 슬라이더**: 탭 버튼으로 시술 전환 (울쎄라피, 쿨소닉, 써펙트) + 예약하기 버튼
- **CTA 섹션**: "당신의 아름다움이 피어나는 곳 — Bloom Your Beauty" + 상담 예약 버튼
- **쁘띠 섹션**: 3개 카드 (Juvelook, Exosome, Rejuran) — 이미지 + 설명 + 시술 바로가기
- **공간 소개 캐러셀**: 내부 사진 슬라이드
- **위치/지도 섹션**: 네이버 지도 임베드 + 주소 복사 + 지하철/버스 노선 + 네이버지도/카카오맵/구글맵 링크

### 2. 병원 안내 (/introduce)
- 히어로 배너 이미지
- "YEPIDA" 타이틀 + 소개 텍스트
- Philosophy 섹션 (4가지 가치 반복)
- CTA + 지도 섹션

### 3. 공간 소개 (/introduce/space)
- 공간 사진 갤러리
- 클리닉 내부 인테리어 이미지

### 4. 의료진 소개 (/introduce/staff)
- 히어로: "YEPIDA Doctor" + 소개 문구
- 의사별 카드:
  - 사진 (세로 포트레이트)
  - 이름 + 직위 (대표원장, 부원장, 원장)
  - 약력 (학교)
  - 이력 (경력)
- 5명의 의료진 리스트

### 5. 진료시간 (/introduce/schedule)
- 요일별 진료시간 표
- 평일/토/일/공휴일/점심시간

### 6. 프로모션 (/exhibitions)
- 이벤트 카드 그리드
- 이미지 + 제목 형태

## 디자인 특징

### 컬러
- **Primary**: 골드/베이지 톤 (고급스러운 느낌)
- **Background**: 화이트 / 크림
- **Text**: 다크 그레이 (#222 ~ #333)
- **Accent**: CTA 버튼에 포인트 컬러

### 타이포그래피
- 영문: 세리프 + 산세리프 혼합 (Bloom Your Beauty = 세리프)
- 한글: 산세리프 (깔끔)
- 대비: 큰 영문 헤딩 + 작은 한글 설명

### 레이아웃
- 풀스크린 이미지 히어로
- 넓은 여백 (padding/margin 크게)
- 섹션별 배경색 변화로 구분
- 카드형 UI (시술, 프로모션)
- 가로 스크롤 캐러셀 (공간 사진, 시술)

### 반응형
- 데스크탑: 가로 배치, 넓은 레이아웃
- 모바일: 세로 스택, 하단 고정 바 (4개 버튼)

### UX 특징
- 팝업 프로모션 (첫 방문 시)
- 하단 고정 바 (항상 접근 가능한 CTA)
- 플로팅 챗봇 버튼
- 지도에 네이버/카카오/구글 3종 연동
- 주소 복사 버튼
- 대중교통 안내 (지하철 + 버스)

## 푸터 구성
- 전화번호 + 상담 유도 문구
- 진료시간 표 (평일/토/일/공휴일)
- 법적 링크: 이용약관, 개인정보처리방침, 미성년시술동의서
- 사업자 정보: 상호, 사업자번호, 대표자, 주소, 전화번호

## 템플릿 변환 시 핵심 섹션 (재사용 가능)
1. 히어로 배너 (풀스크린 이미지 + 오버레이 텍스트)
2. 철학/가치 섹션 (아이콘 + 제목 + 설명 x 4)
3. 시술/서비스 슬라이더 (탭 전환)
4. CTA 섹션 ("Bloom Your Beauty" 스타일)
5. 카드 그리드 (이미지 + 제목 + 설명 + 버튼)
6. 의료진/팀 소개 (사진 + 이력)
7. 공간 캐러셀 (이미지 슬라이드)
8. 위치/지도 섹션 (지도 + 주소 + 대중교통)
9. 프로모션 그리드
10. 하단 고정 CTA 바
11. 푸터 (진료시간 + 사업자정보)
